# Troubleshooting Reference

當你遇到困難時，請使用本參考資料。請先從相關章節開始，然後檢查症狀和後續動作。

## Chapter 00: Setup

相關章節：[00 Setup](../00-setup/)

| 症狀 | 可能原因 | 嘗試這樣做 |
|---|---|---|
| 登入失敗 | 帳戶、網路、SSO 或 GitHub Enterprise Cloud 登入問題 | 確認帳戶、瀏覽器登入和網路存取。如果你的組織使用 `*.ghe.com`，請選取 **Sign in to GitHub Enterprise Cloud** |
| 無法存取應用程式 | Copilot 方案、自有的模型提供者或組織原則 | 確認已有 Copilot 方案或已設定的模型提供者。對於 Business 或 Enterprise，請確認已啟用 **GitHub Copilot app** 原則（它與 Copilot CLI 原則是分開的） |
| 偵測不到 Git | 缺少 Git 或 Git 不在 PATH 中 | 安裝 Git 並重新啟動應用程式 |
| 在 Windows 上，`npm` 因為已停用執行指令碼而失敗 | PowerShell 的執行原則封鎖了 `npm.ps1` | 使用 `npm.cmd` 取代 `npm`。若要使用其他修正方式，請開啟[在終端機中檢查你的工具](../00-setup/README.zh-Hant.md#check-your-tools-in-terminal)中的 Windows 章節 |
| 存放庫沒有出現 | 存放庫存取權限或選擇器篩選條件 | 檢查帳戶存取權限、組織成員資格、存放庫權限，以及應該新增本機資料夾、GitHub 存放庫還是 URL |
| 聊天無法摘要存放庫 | 存放庫未連接，或脈絡太廣 | 重新連接專案，並要求提供課程存放庫的簡短概觀 |

## Chapter 01: Tour the App

相關章節：[01 Tour the App](../01-tour-the-app/)

| 症狀 | 可能原因 | 嘗試這樣做 |
|---|---|---|
| 不確定要使用哪種模式 | 這些模式聽起來像技能等級 | 探索時使用 Chats，想先擬定方法時使用 Plan，想逐步引導時使用 Interactive，處理清楚且低風險的任務時使用 Autopilot |
| 回應緩慢或成本高 | 模型、推理強度或脈絡超出所需 | 對簡單任務降低推理強度，並且只附加有用的脈絡 |
| 設定看起來與螢幕擷取畫面不同 | 應用程式版本或平台差異 | 檢查應用程式版本。標籤和版面配置可能因版本和平台而異 |
| 語音聽寫無法運作 | 麥克風權限或本機轉錄模型 | 檢查作業系統的麥克風權限、語音設定、已下載的模型、快速鍵和語言支援 |
| 找不到鍵盤快速鍵 | 平台或應用程式版本差異 | 開啟 Help 或設定，並使用已安裝版本的快速鍵清單 |

## Chapter 02: Sessions, Worktrees, and Context

相關章節：[02 Sessions, Worktrees, and Context](../02-sessions-worktrees-context/)和 [Git Worktrees](git-worktrees.zh-Hant.md)

| 症狀 | 可能原因 | 嘗試這樣做 |
|---|---|---|
| 工作階段的編輯出現在意外的資料夾中 | worktree 路徑或分支混淆 | 在應用程式中檢查工作階段詳細資料、分支名稱和 worktree 路徑 |
| 找不到 worktree | 資料夾被手動移動或刪除 | 優先使用應用程式的清理功能。如果已刪除，請關閉工作階段，並在可行時從分支或 PR 重新建立該工作 |
| 兩個工作階段衝突 | 它們編輯了相同的檔案或共用資源 | 暫停其中一個工作階段，比較 diff，並決定哪個分支作為依據的來源 |
| Web 伺服器無法啟動 | 連接埠已被使用 | 停止未使用的伺服器，或讓第二個工作階段使用另一個連接埠，例如 `5174` |
| 工作階段與主要簽出內容不同 | 相依套件、分支內容、環境或產生的檔案不同 | 在工作階段的 worktree 中執行安裝和驗證命令 |
| 脈絡雜亂 | 檔案太多或提示太籠統 | 使用聚焦的 `@` 檔案或資料夾參考，以及較小的任務 |
| 回應包含太多無關的細節 | 應用程式範圍的指引或脈絡雜亂 | 保持 **Settings → Sessions** 中的應用程式指引簡短，並且只附加相關檔案 |
| 難以辨識分支名稱 | 未設定分支前置詞 | 設定可識別 GitHub Copilot app 工作階段的專案或應用程式分支前置詞 |

## Chapter 03: Development and GitHub Workflows

相關章節：[03 Development and GitHub Workflows](../03-development-workflows/)

| 症狀 | 可能原因 | 嘗試這樣做 |
|---|---|---|
| 測試只在一個工作階段中失敗 | 相依套件或分支不一致 | 在該 worktree 中重新安裝相依套件，並檢查分支內容 |
| 瀏覽器預覽沒有更新 | 開發伺服器、熱重載或連接埠錯誤 | 在正確的 worktree 中重新啟動伺服器，並確認瀏覽器 URL |
| Diff 難以信任 | 無關的變更太多 | 要求代理程式說明 diff，然後拆分或還原無關的編輯 |
| Pick & Polish 的變更損害了協助工具 | 視覺更新改變了對比、版面配置或標籤 | 以協助工具目標進行檢閱，並重新執行測試或手動檢查 |
| Issues 或 Pull requests 檢視中缺少 issue 或 PR | 索引標籤錯誤、查詢篩選條件或權限問題 | 檢查所選的索引標籤和查詢中的 `repo:` 項目，檢查存放庫存取權限，並確認指派或檢閱要求 |
| 無法推送分支 | 沒有上游的寫入權限 | 使用 fork 或你有寫入權限的存放庫 |
| CI 失敗但本機測試通過 | 環境、祕密或分支保護不同 | 閱讀失敗的檢查記錄，並比較 Node 版本、命令和祕密 |
| PR 仍然被封鎖 | 必要的檢閱、檢查、分支保護或衝突 | 依此順序分類處理：失敗的檢查、合併衝突、必要的檢閱、過時的檢閱、分支規則 |
| 無法使用 Agent Merge | 原則、權限或存放庫設定 | 將 Agent Merge 視為進階功能，改用手動檢閱或合併流程 |
| 平行的工作階段重複工作或發生衝突 | 任務並非互相獨立，或分支修改了相同的檔案 | 暫停，比較 diff，指定一個工作階段作為依據的來源，並手動解決衝突 |

## Chapter 04: Skills and Custom Agents

相關章節：[04 Skills and Custom Agents](../04-skills-custom-agents/)

| 症狀 | 可能原因 | 嘗試這樣做 |
|---|---|---|
| Copilot 忽略專案樣式 | 指引缺失或太籠統 | 將穩定的專案指南放在 `.github/copilot-instructions.md` 中 |
| 技能似乎沒有套用 | 技能位置、中繼資料或提示不符 | 檢查 `.github/skills/.../SKILL.md`，並在提示中說明該技能的用途。在應用程式中，開啟 **Customize → Installed**，將類型篩選條件設為 **Skills**，並在技能名稱下方尋找 **Project:** |
| 找不到 Skills 或 Custom Agents | 在 Settings 中尋找，而不是在相關的選擇器中 | 開啟 **Customize → Installed**，並將類型篩選條件設為 **Skills**。對於自訂代理程式，請使用 `/agent` 或提示方塊的代理程式選擇器 |
| 找不到新的自訂代理程式 | 設定檔儲存在 worktree 之外，或尚未重新載入 | 檢查目前 worktree 中的 `.github/agents/book-app-explainer.agent.md`。請依照章節中同一工作階段的重新啟動指示操作 |
| 自訂代理程式無法執行測試 | explainer 只有讀取和搜尋工具 | 回到預設代理程式；請勿擴大 explainer 的工具 |
| 代理程式的工具太多 | 工具組增加了雜訊和風險 | 停用任務不需要的工具 |

## Chapter 05: MCP Servers and Plugins

相關章節：[05 MCP Servers and Plugins](../05-mcp-plugins/)

| 症狀 | 可能原因 | 嘗試這樣做 |
|---|---|---|
| 在 Settings 中找不到 MCP 或 Plugins | 自訂項目位於側邊欄中 | 開啟 **Customize**，然後將類型篩選條件設為 **MCP** 或 **Plugins** |
| MCP 伺服器失敗 | 驗證、網路或原則問題 | 檢查連線狀態、URL、認證和組織原則。請勿將認證放入提示或存放庫檔案中 |
| 缺少外掛程式功能 | 外掛程式已停用，或其技能尚未載入 | 在 **Customize → Installed** 索引標籤上檢查 **Plugins**，執行 `/skills reload`，並尋找帶有外掛程式前置詞的技能名稱。必要時請依照章節中的重新啟動指示操作 |
| 代理程式無法使用整合 | 仍選取了唯讀的 explainer，或工具存取被封鎖 | 如果提示方塊下方出現代理程式選擇器，請選取 **Default agent**。然後檢查核准和原則 |
| 整合被原則封鎖 | 不允許安裝或外部存取 | 閱讀範例和預期輸出，記錄限制，並在不變更原則的情況下繼續 |

## Chapter 06: Canvases

相關章節：[06 Canvases](../06-canvases/)

| 症狀 | 可能原因 | 嘗試這樣做 |
|---|---|---|
| 畫布無法開啟 | 缺少 `/create-canvas`，或延伸模組語法、相依套件或重新載入問題 | 重試 `/create-canvas`，或在工作階段中以 markdown 保留同一個看板 |
| 畫布狀態看起來過時 | 儲存的狀態與可見的 UI 不同步 | 重新整理畫布，或重新執行會更新狀態的動作 |
| 代理程式動作失敗 | 功能名稱或輸入結構描述不符 | 檢查動作名稱、必要欄位和儲存的狀態 |
| Workbench 動作持續停用 | 螢幕擷取畫面或瀏覽器檢查無法執行，而畫布將其視為必要項目 | 使用練習 3 中的 **An action stays disabled** 修復提示 |
| 記錄證據後，動作顯示錯誤 | 畫布正在等待相符的聊天回覆 | 使用練習 3 中的 **An action shows an error after its work is done** 修復提示 |
| 畫布包含私人內容 | 共用介面被當作私人筆記使用 | 從畫布中移除祕密資訊、私人存放庫詳細資料和客戶資料 |

## Chapter 07: Automations

相關章節：[07 Automations](../07-automations/)

| 症狀 | 可能原因 | 嘗試這樣做 |
|---|---|---|
| 手動自動化沒有執行 | 應用程式、專案或工具相依項目無法使用 | 確認應用程式已開啟、專案存在，且已安裝必要的工具 |
| 排程沒有執行 | 本機電腦處於睡眠狀態，或雲端設定無法使用 | 在初學者練習中使用手動執行，或確認雲端自動化的先決條件 |
| 無法使用雲端自動化 | 原則、計費、存放庫或權限問題 | 將其視為進階功能，閱讀選用章節，並繼續使用本機自動化 |
| Issue 觸發程序觸發太頻繁 | 觸發程序太廣泛 | 縮小存放庫、標籤、issue 查詢或工具權限的範圍 |

## 一般規則

如果代理程式說任務已完成，仍要檢查證據。良好的課程工作流程會以可見的驗證作結：diff、測試、建置、瀏覽器預覽、PR 檢查或檢閱結果。
